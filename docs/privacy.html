Privacy Policy

Draw on Web is built to respect your privacy completely.

Last updated: 25 September 2026

Draw on Web does not collect, transmit, sell, or share any of your data. There are no servers, no analytics, no tracking, and no external network requests. Everything the extension stores stays on your own device (or within your own Google account, if you use Chrome Sync).

What the extension stores

To function, the extension saves a small amount of data locally using the browser's built-in storage APIs:

  • Your settings (tool defaults, colours, toolbar layout, theme, input-device preference, and so on) are stored via Chrome's synced storage. If you are signed into Chrome, these preferences travel with your own Google account across your Chrome installs. They are never sent to the developer or any third party.
  • Your drawings (the annotations you create) and the toolbar position are stored in local storage, which never leaves your device. Drawings are keyed by page URL only, so they can be re-attached to the correct page. Auto-restore of drawings is off by default.

What the extension does not do

  • It does not collect personally identifiable information.
  • It does not track your browsing history or send your visited URLs anywhere.
  • It does not contain analytics, telemetry, or advertising code.
  • It does not make network requests or load remote code — all code ships inside the extension package.
  • It does not sell or transfer any data to third parties.

Permissions & why they're needed

  • activeTab / host access — used solely to draw the annotation canvas onto the page you are currently viewing. No page content is read, stored off-device, or transmitted.
  • scripting — used to inject the drawing canvas and toolbar into the page.
  • storage — used to save your settings and drawings locally, as described above.
  • Host access (<all_urls>, file:///*) — required so you can draw on whichever page you are currently viewing, including local files.

Third-party services

The extension itself uses no third-party services and makes no network requests. This support website is served by a static hosting provider and loads a web font from Google Fonts; standard server request logs may apply to the website as they would for any website. The extension does not use these.

Removing your data

You can clear all saved drawings and reset all settings at any time from the extension's Options page (Clear saved drawings and Reset to defaults). Uninstalling the extension removes all locally stored data.

Children's privacy

Draw on Web is a general-purpose annotation tool. It collects no data from anyone, including children.

Compliance

Because Draw on Web collects and transmits no personal data, there is no personal data to access, export, or erase on our side. The extension is designed to align with the principles of privacy regulations such as the GDPR and CCPA and with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes to this policy

This policy may be updated if the extension's functionality changes. Any material change will be reflected in the "Last updated" date at the top of this page.
